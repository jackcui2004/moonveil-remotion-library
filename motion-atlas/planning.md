# 小说分镜 → 效果编号 → 素材复用

这份库有 65 项自制 Remotion 效果，按九种叙事用途组织。效果编号用于表达镜头意图，不要求一篇小说把所有效果都用一遍。

## 九类怎么选

| 分类 | 用来回答 | 照片策略 |
|---|---|---|
| 基础运镜 | 观众接下来要看哪里？ | 通常1–3张既有图 |
| 人物与情绪 | 谁在想什么，情绪如何变化？ | 人物图/抠图复用；新动作缺失才补 |
| 悬念与揭示 | 先隐藏什么，随后揭露什么？ | 大多1张原图裁切；多层揭秘可2–3张 |
| 转场与纸张 | 两个情节如何衔接？ | 直接引用相邻镜头的图 |
| 关系与调查 | 谁和谁、哪些证据有联系？ | 多图但优先全复用，不另生“关系图照片” |
| 文档与证据 | 哪一句、哪个信息构成证据？ | 文字、信封、纸张可代码生成，0照片起用 |
| 时间与回忆 | 什么时候，前后如何变化？ | 回忆引用当时原图；新年龄/新状态才新增 |
| 对照与分支 | 两边差异、交集或抉择是什么？ | 两图对照或0图图表 |
| 标题与收束 | 这一段的主题和结论是什么？ | 场景复用，文字排版承担重点 |

## 逐条分镜工作顺序

1. 分出剧情事件和旁白锚点，写清每条镜头的叙事目的。
2. 先确定“独立剧情画面”，为每张原图分配稳定的 image_id。人物、地点、动作、服装或年代发生关键变化，才考虑新图。
3. 再为镜头选效果编号，并引用 image_id。裁切、抠图遮罩、拼图和缩略图是派生用法，保留 parent_image_id。
4. 标清 reveal_text、relationship_edges、timeline_events 等数据。代码绘制的图表不先生成文字图片。
5. 从图像清单反查缺口，只有缺口进入生图清单。不要把每个图板位置都当成一张新图。
6. 根据真实配音的词边界设置运动与停稳窗口。演示的6/7秒是展示节奏，不是正文固定镜头时长。
7. 关键视频作为独立素材选择，通常替换高潮动作镜头；这些65项本身没有强制视频预算，图片即可运行。

## 数照片的例子

一个章节有12个独立剧情画面，另加人物关系板、证据板、回忆卷各一次：

- 剧情镜头用 IMG01–IMG12，共12张。
- 关系板引用 IMG02、IMG05、IMG08：新增0张。
- 证据板用代码排合同，再引用 IMG09：新增0张。
- 回忆卷引用 IMG01、IMG04、IMG06：新增0张。
- IMG05裁成近景、抠出人物、放进手机：仍然是同一张源图，遮罩不算新剧情图。
- 如果结尾需要之前没有的“多年后重逢”状态，再新增 IMG13。

最终是12或13张独立源图，不是镜头数加上所有板面图位。不同小说的章节时长与事件密度不同，不统一规定每章张数。

## 常用搭配

- 平静叙述：001局部揭全景 → 稳定阅读 → 005匹配接镜。
- 查出秘密：021放大镜 → 034涂黑揭密 → 055共同线索 → 065收束。
- 解释关系：041图钉连线 → 008拉远关系网 → 062排除。
- 回忆：013时间回拨 → 039胶片 → 009今昔对位。
- 人物独白：022移焦 → 057证词；切换表情时可静音叠化。
- 章节交接：036标题让位 / 060章节索引 / 029翻页择一即可。

这些是选择示例，不是必须连续串联的模板。一个语义节点通常只用一个主要动作，先让观众读清再换镜头。

## 工程里怎么复用

```tsx
import Effect007 from './effects/007';

<Effect007
  photos={[
    'episode/ch01/IMG02.png',
    'episode/ch01/IMG05.png',
    'episode/ch01/IMG08.png',
  ]}
/>
```

photos 最多提供5个槽位，少于5张时循环引用原图；真正需要不同角色/证据的位置不要用重复图冒充。图片需要放在工程 public 下，路径不带 public/。people 目前有 elena 和 julian 两个演示槽位，可以替换为自己的 image/mask 路径，人物语义与文案也一起改。

```tsx
<Effect004
  photos={['episode/room.png']}
  people={{elena:{image:'episode/hero.png',mask:'episode/hero-mask.png'}}}
/>
```

人物遮罩是与图片尺寸一致的灰度亮度遮罩。文字、关系边、镜头目标、时间点目前在 CameraAtlas*.tsx 的对应实现中配置；当前不是任意小说一键编排器。EffectPlayer 负责把独立条目播放窗口对齐，65个入口文件依赖共享组件。

## 文件安排

- `catalog.json` / `catalog.csv`：65项分类、图片预算和素材要求。
- `effects/001.md` … `065.md`：每项分镜说明。
- `project/src/effects/001.tsx` … `065.tsx`：可单独引用的入口。
- `project/src/CameraAtlas*.tsx`：完整动画实现与共享素材组件。
- `project/scripts/`：打包和6路独立渲染、音轨与合集组装。
- `videos/001.mp4` … `065.mp4`：独立视频。
- `videos/All-65.mp4`：完整6分45秒合集。
- `storyboard-template.csv`：以后小说分镜的统一字段。

## 声音

只在001、003、006、011、014保留极轻点击；其余条目有意静音。没有小说旁白、连续音乐或dong音效。正式制作时按语义决定，人物表情和叠化通常保持静音。
