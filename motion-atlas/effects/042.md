# 042 · 放射式人物板

- 分类：关系与调查
- 适合分镜：交代中心人物与周围人的关系
- 独立源照片建议：**4–5 张**；这是可适配预算，不是每次必须新生成。
- 新增图：0（现有图满足情节时）；缺失人物、地点或状态才新增
- 复用方法：中心抠图加3–4张旧图
- 额外输入：人物抠图可选
- 原演示时长：6 秒；小说中通常只在交接的短窗口运动，中间停稳，不能直接循环填满旁白。
- [效果视频](../videos/042.mp4) · [入口源码](../project/src/effects/042.tsx)
- 共享实现：`project/src/CameraAtlas*.tsx`，入口依赖 `EffectPlayer.tsx`，不是单文件无依赖效果。

## 套用

1. 给本条分镜标注效果编号 `042`，先从素材表挑已有图。
2. 以 public 相对路径传入 `photos`；人像效果传 `people` 的 image 和 mask。
3. 同一个源图的裁切、网格副本、分层遮罩都引用原素材 ID，不计新图。
4. 按剧情修改实现里的文字、节点和时间点；`photos`/`people` 已接参数，文本和关系目前仍在共享源码中配置。

```tsx
import Effect042 from './effects/042';
<Effect042 photos={['my/ch01-scene.png','my/ch01-person.png']} />
```
