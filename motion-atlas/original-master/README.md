# 原始高质量合集

网页直接播放的是1080p/30fps的CRF26播放版。这里保留原始CRF18/veryfast总装文件的完整字节，不改变65个独立视频。

由于GitHub连接器单次传输限制，原始合集分为八个二进制卷。分卷不是两个可播放MP4；需要按顺序还原。

下载本目录的manifest.json和restore.py，然后运行：

```sh
python3 restore.py All-65-original.mp4
```

缺少的卷会从本站自动下载。脚本先核对每卷的SHA256，再按字节拼接，最后核对完整文件的SHA256。也可以手动下载全部分卷后离线运行。

- 原始时长：405秒 / 6分45秒。
- 原始帧数：12150；1920×1080，30fps。
- 音频：5次极轻点击，其他时间有意静音。
