# Moonveil · Remotion制作流程库

可公开分享的制作流程、脚本和音效/风格参考资料库。

先打开index.html；包含九步说明、8条音效试听、Vox公开视频与源码参考、并行渲染和实时进度工具。

已验证、新增基础验证、只读参考和待实现分开标注。部分案例源码需适配自己的媒体、原文、时间轴和路径，不是一个空目录即可渲染的完整故事工程。

公开版不含私人文章全文、完整字幕时间轴、个人目录与私人生产记录。新资料放08，补来源和备注，再运行python3 09_维护工具/更新目录.py。

## GitHub Pages

Settings → Pages → Deploy from a branch → main / (root)。根目录有index.html和.nojekyll，无需构建依赖。
